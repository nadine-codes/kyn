/ THE PITCH

Kyn is a multi-agent system where a supervisor decides which capabilities to call — Code, Company, Memory, or Action — based on what each problem actually needs.

/ 01 — CAPABILITIES

Four sub-agents. One supervisor. Whatever the problem needs.

/ AGENT 01 · CODE
Code
Reads and writes your repo. Traces commits, opens pull requests, runs scoped tests. Speaks GitHub natively.
/ AGENT 02 · COMPANY
Company
Synthesizes context across Slack, Gmail, Notion, contracts. Knows who owns what and what was decided last quarter.
/ AGENT 03 · MEMORY
Memory
Records what worked, what didn't, what the team decided. Recalls it on the next run, so you never explain twice.
/ AGENT 04 · ACTION
Action
Drafts the customer reply. Opens the PR. Files the incident. Real artifacts, ready to ship — with you in the loop.
